# QR Code Generator

A simple Python application that generates QR codes from user-provided URLs using the `qrcode` library.

## 🚀 Features

- Generate QR codes from any URL
- Save the QR code as a PNG image
- Fast and easy to use
- Beginner-friendly Python project

## 🛠 Technologies Used

- Python
- url
- Pillow

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/surajrawatdavstudent-creator/QR-Code-Generator.git
```

Install the required package:

```bash
pip install qrcode[pil]
```

## ▶️ Usage

Run the program:

```bash
python Project.py
```

Enter any URL when prompted, and the QR code will be generated and saved as `qrcode.png`.
